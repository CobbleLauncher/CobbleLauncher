隐私声明

生效及最近更新日期：2026 年 10 月 22 日

本声明说明 CobbleLauncher 当前官方网站及现有启动器功能涉及的数据处理。网站由 CobbleLauncher 项目维护者提供，隐私问题可发送至 cobble-launcher@yuzhes.com。

1. 官方网站

本网站是托管于 Cloudflare Pages 的静态网站，没有注册表单、评论功能或自建账号数据库。当前页面不加载广告、访问分析脚本、第三方字体或嵌入式社交组件，也不主动设置 Cookie 或使用浏览器本地存储。

为交付页面和保护网络，Cloudflare 会处理 IP 地址、请求 URL、时间、浏览器及连接信息，并可能根据其安全设置使用必要的安全机制。相关处理、存储地点与保留安排适用 Cloudflare 隐私政策。本网站没有另行建立访客档案。

2. 启动器中的本地数据

现有启动器在设备上保存玩家档案、偏好设置、游戏安装信息及相关文件。离线档案包括你输入的玩家名、由玩家名生成的离线 UUID，以及你选择填写的备注。这些档案用于本地选择身份和启动游戏，不代表 Microsoft 账号认证。

本地游戏及组件可能生成日志，其中可能包含用户名、设备路径、游戏信息或第三方组件输出。请在分享日志之前检查并删除敏感内容。删除游戏或卸载启动器不一定会清除所有独立游戏目录、日志、备份或遗留配置，请按需要手动检查。

3. 下载、搜索与第三方连接

查询版本、安装游戏、搜索或更新模组等操作会连接相应服务，例如 Minecraft 官方服务、BMCLAPI、Modrinth、模组加载器服务或你配置的下载源。接收请求的服务会获得连接所需的网络信息，例如 IP 地址，以及完成操作所需的搜索词、版本、文件标识或文件哈希。实际发送内容取决于你使用的功能和版本。

第三方服务按其自己的规则处理数据。你可以在使用前查看 Microsoft 隐私声明、Modrinth 隐私政策，以及所选镜像或下载源的说明。第三方模组和游戏服务器也可能独立处理数据，不受本声明控制。

4. Microsoft 账号登录

当前版本尚未提供 Microsoft 账号登录，网站也不接收 Microsoft 密码、访问令牌或刷新令牌。发布者域验证文件中的应用 ID 是公开标识，不包含账号凭据。

Microsoft 登录上线前，我们将更新本声明，说明授权范围、账号数据、令牌存储、退出与撤销授权方式。请勿通过邮件或 GitHub Issues 向维护者发送密码或令牌。

5. 主动联系与公开反馈

如果你发送邮件，维护者会收到你的邮箱地址、邮件内容和附件，用于回复及处理问题。若你在 GitHub 提交 Issue 或其他公开内容，相关信息通常公开可见，并受 GitHub 的条款和隐私政策约束。

支持沟通将按解决问题及履行适用法律义务的需要保留。你可以通过联系邮箱申请查询或删除维护者持有的相关沟通记录。第三方平台和托管服务所保存的记录需要依其相应渠道处理。

6. 你的选择与权利

你可以停止访问网站、停止使用启动器、更换下载源、删除本地玩家档案和相关文件，或不提交可选反馈。根据所在地法律，你可能享有访问、更正、删除、限制处理、反对处理或投诉等权利。请通过联系邮箱提出请求，我们会依适用法律处理，并在必要时核实请求人的身份。

网站及相关第三方基础设施可能在你所在国家或地区以外处理数据。当前网站不提供面向儿童的注册或资料收集功能。监护人如认为儿童通过支持渠道提交了不应保留的个人信息，可联系维护者处理。

7. 声明更新

本声明反映当前网站及现有功能。上线账号登录、遥测、云同步或其他涉及不同数据处理的功能前，我们会更新相关说明，并在适用法律要求时取得同意。本页会标明最近更新日期。
